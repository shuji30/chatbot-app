# chatbot-app ブラッシュアップ・ロードマップ

ゴール: `.env.local` で固定したサイト URL と、質問窓に入力した質問を Gemini API
(`gemini-2.5-flash` + url_context ツール)に渡し、サイト内容に基づく回答をチャットに表示する。

進め方: 上から順に、**1 イテレーション = 1 タスク = 1 コミット**。
完了したら `[x]` にし、「履歴」に 1 行追記してからコミットする。
